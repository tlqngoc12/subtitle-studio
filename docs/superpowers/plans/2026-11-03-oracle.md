# Oracle và nền tảng dữ liệu: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Oracle Free thành database chạy hằng ngày qua `docker compose`, schema do Flyway quản lý (một bộ SQL Oracle, H2 `MODE=Oracle` dùng chung), có nhóm test trên Oracle thật.

**Architecture:** Spring profile: `application.yml` (mặc định H2 file `./data/dev`, `MODE=Oracle`) và `application-oracle.yml` (Oracle, thông tin đăng nhập từ biến môi trường). Flyway chạy `db/migration/V1__init.sql` trên cả hai DB; Hibernate `validate`. Test thường chạy H2 in-memory; `*OracleIT` chạy bằng failsafe + Testcontainers trong Maven profile `oracle`.

**Tech Stack:** Spring Boot 3.5.16, Flyway 11.7.2 (`flyway-core` + `flyway-database-oracle`), `ojdbc11` 23.7, Testcontainers 1.21.4 (`oracle-free`), image `gvenzl/oracle-free:23.26.3-slim-faststart`.

**Spec:** [docs/superpowers/specs/2026-11-03-oracle-design.md](../specs/2026-11-03-oracle-design.md)

## Global Constraints

- Image Oracle duy nhất, dùng ở compose **và** Testcontainers: `gvenzl/oracle-free:23.26.3-slim-faststart`.
- Version thư viện lấy từ Spring Boot BOM, không ghi version riêng (trừ plugin đã có).
- Mọi cột chuỗi Oracle là `VARCHAR2(n CHAR)`.
- Không sửa migration đã **push** hoặc đã chạy trên Oracle thật của người dùng; thay đổi schema = file mới `V{n}__mo_ta.sql`. Trong plan này `V1__init.sql` còn được chỉnh ở Task 1 và Task 3 (chưa push, chưa có dữ liệu thật) cho tới khi pass trên cả H2 và Oracle.
- Sequence `cue_seq`, `vi_cue_seq`: `INCREMENT BY 50`, khớp `allocationSize = 50`.
- Hibernate `ddl-auto: validate` ở mọi môi trường (kể cả test).
- Oracle profile: user/mật khẩu từ `SUBTITLESTUDIO_DB_USER` / `SUBTITLESTUDIO_DB_PASSWORD`, **không** giá trị mặc định; host từ `SUBTITLESTUDIO_DB_HOST` (mặc định `localhost`); service `FREEPDB1`, cổng 1521.
- User ứng dụng Oracle: `subtitle_studio`. Cổng host chỉ bind `127.0.0.1:1521`.
- Không xoá `./data/subtitle-studio.mv.db` (H2 cũ). H2 dev dùng file mới `./data/dev.mv.db`.
- REST API và frontend không đổi.
- Lệnh test backend nhanh: `mvn -q test -Dskip.npm` (bỏ bước frontend).

## Review Focus

Những tình huống spec ngụ ý nhưng dễ bị bỏ sót; mỗi dòng có kiểm tra ở task tương ứng:

1. **Chạy compose khi thiếu `.env` / mật khẩu** → compose dừng với thông báo rõ, không khởi động app với mật khẩu rỗng. (Task 4, Step 2)
2. **Tiêu đề/văn bản có emoji (UTF-8 4 byte) và chữ Thái dài** → lưu và đọc lại nguyên vẹn trên Oracle. (Task 3, `storesEmojiAndLongThaiTitle`)
3. **Câu Vietsub dài 1000 ký tự tiếng Việt có dấu** → lưu được (không vượt do đếm byte). (Task 3, `storesThousandCharVietnameseCue`)
4. **Oracle restart khi app đang chạy** → app tự kết nối lại, API hoạt động sau khi Oracle healthy lại. (Task 4, Step 6)
5. **Khởi động lại trên volume Oracle đã có dữ liệu** → Flyway không chạy lại V1, `validate` qua, dữ liệu còn. (Task 4, Step 5)
