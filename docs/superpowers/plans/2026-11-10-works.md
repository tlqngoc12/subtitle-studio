# Works Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Works menu (admin + public): poster grid with people and category filters, a detail page with link buttons, optional trailer and cast/artist cards, an editor, and a reusable people directory.

**Architecture:** New `work` backend package (V15: `t_person`, `t_work`, `t_work_link`, `t_work_credit`). Work saves replace the link and credit lists as a whole. The frontend reads through `ReadSource.listWorks()` / `getWork(id)` (API or `works.json` + `works/{id}.json`), reuses part 2's `PeopleFilter` and part 1's resized uploads.

**Tech Stack:** Spring Boot + JPA + Flyway; React + TS, Radix (Dialog, Popover, Select), dnd-kit, simple-icons, lucide-react, vitest.

**Spec:** `docs/superpowers/specs/2026-11-10-works-design.md`

## Global Constraints

- Start after the Photos PR is merged: branch `feat/works` from the latest `main`.
- Flyway `V15__works.sql` (next free number if taken).
- Categories (enum → label): `FILM_TV` Film & TV, `PERFORMANCE` Performance, `MUSIC` Music, `VARIETY` Variety Show, `ADVERTISEMENT` Advertisement, `CEREMONY` Ceremony, `INTERVIEW` Interview, `FASHION` Fashion.
- Link kinds `PILOT | TRAILER | X | INSTAGRAM | OTHER`; default labels Pilot, Trailer, X, Instagram; ≤ 20 links; each non-OTHER kind at most once; URL http(s), ≤ 500 chars; label 1–60.
- Credits ≤ 30, a person at most once per work; role ≤ 40; character ≤ 100 and kept only for `FILM_TV`.
- Role suggestions: Film & TV → Lead, Supporting, Guest, Cameo; Music → Singer, Featuring, Vocal, MV cast.
- Icon keys: `youtube, x, instagram, tiktok, facebook, netflix, spotify, applemusic, line, threads, link` (`link` = lucide `Link2`). iQIYI / WeTV / Viu are not in simple-icons → generic link icon.
- Sorting: `release_date` NULL first, then date desc, then id desc. Dates shown with part 2's `formatDay`; NULL → `Coming Soon`.
- Grid 4 / 3 / 2 columns at ≥ 1024 / ≥ 760 / below; cover aspect 4:5. Covers uploaded with `maxSide=1600`, avatars with `maxSide=400`.
- NavBar admin `Get Engsub | Vietsub | Profile | Works | Photos | Novels` (+ existing Vietsub list entry), public `Vietsub list | Profile | Works | Photos | Novels`.
- Test commands, colour rules, `tsbuildinfo` rule: as in the Profile plan.

## Review Focus

1. **Category changed from Film & TV to Music** after characters were typed: characters are cleared on save, and the editor warns before it hides them ("Character names are removed for non-film works") → Task 3 + Task 8 tests.
2. **Trailer link forms** (`youtu.be/ID?si=…`, `youtube.com/watch?v=ID&t=30`, `youtube.com/shorts/ID`, `m.youtube.com`) all produce the embed; a non-YouTube trailer is just a button → Task 2 + Task 7 tests.
3. **Route clash** `/works/new` vs `/works/:id`; `/works/abc` and `/works/999` show NotFound, not a crash → Task 6/7 tests.
4. **Deleting a person who is credited** → 409 listing the work titles, directory unchanged → Task 4 test.
5. **Work/person media cleanup:** covers and avatars count as references for the 24 h cleanup; replacing a cover deletes the old file only when unused → Task 1 + Task 3 tests.
