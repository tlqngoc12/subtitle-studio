# Photos Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Photos menu (admin + public) showing Instagram posts as a bento grid; each tile is the uploaded first image and links to the post on Instagram.

**Architecture:** New `photo` backend package (`t_photo_post` + profile join, V14) with a JSON CRUD API; images go through part 1's `POST /api/media?maxSide=1600` and their size comes from `t_media.width/height`. The page reads through `ReadSource.listPhotos()` (API in admin, `photos.json` on the public site) and pages in the browser.

**Tech Stack:** Spring Boot + JPA + Flyway; React + TS, Radix Dialog/Popover, vitest.

**Spec:** `docs/superpowers/specs/2026-11-10-photos-design.md`

## Global Constraints

- Start only after the Profile PR (`feat/profile-single-page`) is merged: branch `feat/photos` from the latest `main` (no stacked PRs).
- Flyway `V14__photos.sql` (next free number if taken). Conventions as V1–V13.
- Instagram link stored as `https://www.instagram.com/{p|reel|tv}/{code}/`; hosts `instagram.com`, `www.instagram.com`, `m.instagram.com`.
- Title 1–200 chars; `photoCount` 1–99 or null; `takenUntil` ≥ `takenOn`; source `OFFICIAL | MEDIA | FAN` shown as `Official`, `Media`, `Fan`.
- Grid: 4 columns ≥ 1024 px, 3 ≥ 760 px, 2 below; row height 200 px (160 px below 760 px); `grid-auto-flow: dense`; ratio `r = height / width`: `r ≥ 1.2` → 1×2, `r ≤ 0.8` → 2×1, else 1×1. First 24 tiles, `Load more` adds 24.
- Dates displayed `9 Nov 2026`, ranges `31 Oct 2026 – 1 Nov 2026` (en dash with spaces).
- NavBar admin: `Get Engsub | Vietsub | Profile | Photos | Novels` after this plan (Works is inserted before Photos in part 3); public: `Vietsub list | Profile | Photos | Novels`. Keep the existing `Vietsub list` entry where it is today.
- Test commands, colour rules, `tsbuildinfo` rule: as in the Profile plan.

## Review Focus

1. **Share links with tracking** (`https://www.instagram.com/p/DQx1abc/?igsh=xyz`, `…/reel/…`, `instagram.com/emiamily/p/DQx1abc`) normalise to the same stored link, so pasting the same post twice gives 409 → Task 2 table test.
2. **Date shifting:** `"2026-11-09"` must display `9 Nov 2026` in every time zone (no `new Date("yyyy-mm-dd")`, which parses as UTC) → Task 5 test with `TZ=America/Los_Angeles`.
3. **Photo media deleted by the 24 h cleanup** because `t_photo_post` is not a reference → Task 1 test.
4. **Old image without width/height** (uploaded without `maxSide`) passed as `mediaId` → 400 on `mediaId`, not a 500 → Task 3 test.
5. **Ctrl+V with text** (not an image) in the dialog's link field must paste the text normally, not be swallowed → Task 7 test.
