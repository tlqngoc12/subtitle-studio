# Fanfics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Fanfics tab inside Novels listing Wattpad stories as Wattpad-style cards, filled by pasting a story link.

**Architecture:** New backend package `fanfic` (link parser, Wattpad HTTP client, service, controller, `t_fanfic`); covers stored through `MediaService.storeResized`; export `fanfics.json`; frontend tab on the admin and public Novels pages reading through `ReadSource`.

**Tech Stack:** Spring Boot (RestClient), Flyway, React + TS, Radix, lucide-react, vitest.

**Spec:** `docs/superpowers/specs/2026-11-11-fanfics-design.md`

## Global Constraints

- Worktree `.claude/worktrees/fanfics`, branch `feat/fanfics` (from main `ccbb8be`). Another open PR (`fix/works-photos-polish`) adds a migration (V17 `post_url` rename): use **V18** here, and before pushing run `git fetch && ls` on `origin/main`'s migrations — if V18 got taken, renumber.
- Follow `CLAUDE.md` design system (control sizes, `Field`, `SearchBar`, `Select`, Skeleton, Reveal/stagger, motion tokens, nested-form rule, popovers inside dialogs portaled) and the media reference rule.
- Wattpad is called only on Add / Refresh / Refresh all; header `User-Agent: SubtitleStudio`; timeouts 10 s; 500 ms between stories in Refresh all. **Tests never hit the real Wattpad.**
- Reading time `round(wordCount / 230)` minutes, shown `1h 8m` / `45m`; numbers compact (`51K`, `2.1K`).
- UI copy English. No Mature badge, no author/tags on the card.
- Tests: `mvn test -Dskip.npm`, `npm test` (file count check), `npx tsc -b`, `mvn verify -Poracle -Dskip.npm`. Never `git add -A`. No merge/deploy/Publish.
- After Task 4 and after Task 7: commit + PROGRESS.md entry in its own commit.

## Review Focus

1. **Wattpad changes or blocks the API** (HTML instead of JSON, 403, 429): user gets "Wattpad did not answer…" and nothing is half-saved → Task 2 test with a 403/HTML stub.
2. **Story deleted or made private on Refresh all:** that story reports a failure, others still update, the old data stays → Task 3 test.
3. **Same story pasted with different link forms** (`m.wattpad.com`, slug changed, `?utm_…`) → 409 duplicate by `wattpad_id` → Task 1/3 tests.
4. **Huge numbers / zero values** (readCount 12,345,678 → `12.3M`; 0 parts; wordCount 0 → Time `—`) render without NaN → Task 5 test.
5. **Description with emojis/astral characters** (titles use math alphanumerics) stored and shown intact on Oracle (CLOB, CHAR semantics) → Task 1 Oracle IT round-trip.
