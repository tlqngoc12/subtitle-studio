# Novels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menu Novels: upload ảnh chụp theo chương → Gemini đọc + dịch Thái → Việt (kèm sổ tay truyện tự cập nhật) → sửa tay, Draft/Published → Publish vẽ chương thành ảnh có watermark lên trang public có chặn sao chép.

**Architecture:** Package backend mới `com.subtitlestudio.novel` (entity `t_novel*`, service, controller, dịch nền bằng `translationExecutor` như Vietsub). Phần gọi Gemini dùng chung được tách khỏi `GeminiTranslatorImpl` thành `GeminiCaller`. `NovelRenderer` (Java2D) vẽ ảnh lúc Publish, `SiteExporter` xuất JSON chỉ chứa đường dẫn ảnh. Frontend thêm trang quản trị dưới `/novels` và 3 trang public đọc JSON tĩnh.

**Tech Stack:** Java 21, Spring Boot 3.5, JPA, Flyway, `com.google.genai:google-genai` (đã có), Java2D/ImageIO, thư viện WebP ImageIO; React 19 + TS, React Router, Radix Tabs, dnd-kit, lucide-react, Vitest + RTL.

**Spec:** [docs/superpowers/specs/2026-11-05-novels-design.md](../specs/2026-11-05-novels-design.md)

## Global Constraints

- Bảng mới tiền tố `t_`; migration `V5__novels.sql` (kiểm tra lại số V trên `main` trước khi merge); SQL Oracle với placeholder `${bigint}` / `${int}`; không đặt tên cột trùng từ khoá H2.
- Cấu hình qua `SubtitleStudioProperties` (record mới `Novel`), không dùng `@Value`.
- Mỗi lỗi nghiệp vụ là một exception riêng, map sang `ProblemDetail` có `code` trong `ApiExceptionHandler`; dùng lại `TRANSLATION_IN_PROGRESS`, `UNKNOWN_PROFILE`, `GEMINI_NOT_CONFIGURED`, `INVALID_MEDIA`, `MEDIA_TOO_LARGE`.
- Không gọi Gemini thật trong test: dùng `FakeGeminiServer` (đã có) cho client, fake interface cho service.
- Không ghi `GEMINI_API_KEY`, text truyện hay nội dung trả về của Gemini vào log.
- Không commit ảnh chụp/text truyện thật; fixture test tự tạo.
- Frontend: chuỗi giao diện tiếng Anh; cam `--brand` = hành động chính / Published, tím `--brand-2` = đang chọn / Translating / Draft viền, `--danger` chỉ lỗi/xoá; chữ trên cam/tím dùng `--on-brand`; tab gạch chân `tabs__list`/`tabs__tab`; icon `lucide-react`; nút chỉ icon có `aria-label` + `<Tip>`; `EmptyState` cho trang trống; hộp thoại xác nhận `useConfirmDialog`; test truy vấn theo role/label; version package cố định.
- Route client mới phải có trong `SpaForwardController` (+ test).
- Giới hạn từ spec: `pages-per-request` 20; ảnh upload ≤ 10 MB (PNG/JPEG/WebP); nhân vật sổ tay ≤ 30, `profile`/`currentState` ≤ 300 ký tự, `storySoFar` ≤ 2.500, `chapterSummary` ≤ 800, giữ 3 `recentChapters`; sổ tay gửi đi ≤ 12.000 ký tự; text chương trước ≤ 20.000 ký tự cuối; nối lượt ~2.000 ký tự; render 1080×1600, chữ 44px, lề 64, giãn dòng 1.7, watermark ~6%.
- Chạy toàn bộ `mvn test -Dskip.npm` (backend) / `npx vitest run` (frontend) trước khi báo xong mỗi task.

**Hai chỗ plan chốt khác spec (đã ghi để người duyệt biết):**
1. Spec nói "> 20 MB thì dùng File API". Plan **không** dùng File API: ảnh đã nén (cạnh dài ≤ 2.000px, JPEG ~85), lượt nào vượt **15 MB** thì chia nhỏ thêm theo dung lượng. Ít code hơn, cùng kết quả.
